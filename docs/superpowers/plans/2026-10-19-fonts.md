# 字体系统 Implementation Plan（spec 2026-10-19-font-system-design.md）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** UI/代码字体双槽（family+size）可配；预设清单+手输；网络字体（URL+本地上传）IndexedDB 缓存与管理（启停/删除/样张）；代码字号联动虚拟滚动行高。

**Architecture:** settings 增 `fonts` 节 → theme.ts 同模式新增 applyFonts（独立 style#vv-font 注入节点）→ 中心化订阅点变更时 CSS 注入 + 激活 tab rev++ 重渲染；行高经 `opts.lineMetrics` 渲染协议传入 code/hex（core virtualScroller 本就以 lineHeight 为参数，零改动）；网络字体走 IndexedDB v3 `fonts` store + FontFace 生命周期管理。

**Tech Stack:** FontFace API、IndexedDB（session.ts db() 升级模式）、CSS 变量、vitest（fake-indexeddb）/playwright。

**Spec:** `docs/superpowers/specs/2026-10-19-font-system-design.md`

## Global Constraints

- 行高公式 `lineHeight = max(16, round(codeSize × 1.5))`；字号 clamp uiSize 10–28 / codeSize 9–28。
- 双槽语义：uiFamily/uiSize 作用于 body 继承面；codeFamily/codeSize 作用于 `.vv-code-pre`/`.vv-hex-dump`/markdown 行内 code 相对值不变。
- `opts.lineMetrics?: { fontSize: number; lineHeight: number }`（Renderer.render opts 协议扩展，`opts.signal` 先例）；缺省回落现值（code 13/20、hex 同字号归一）。
- family 注入前 CSS 转义（引号/反斜杠/分号），自定义名不拆栈（用户输入的逗号栈整体作为一个 family 声明值）。
- 网络字体：仅 https；单文件 >30MB 拒收；fetch 失败入列表错误态可重试；woff2/woff/ttf/otf。
- IndexedDB v2→v3：新增 `fonts` store（id 主键）`{ id, name, family, kind: 'url'|'file', data: ArrayBuffer, url?, size, enabled, addedAt }`；多计划协同——本计划先落地占 v3。
- settings 存 localStorage 'vviewer:settings' 的 `fonts` 节：`{ uiFamily: string; uiSize: number; codeFamily: string; codeSize: number }`（family ''=默认栈）。
- 每任务原子提交；测试在仓库根跑。

### 实施风险与裁决预留

- hex 行高来源形态未知（CSS vs 常量）——Task 2 实读校准；若 hex 行高纯 CSS 派生则 lineMetrics 仅记录语义、虚拟化常量同步值。
- renderMarkdownBody/其他 render opts 消费点是否需要同步 lineMetrics 默认（本地 markdown 渲染无虚拟滚动——不需要）。
- queryLocalFonts/宽度探测为 spec 拍板不做——实现者不得擅自引入。
- FontFace 的 jsdom 缺失——测试以 mock FontFace + document.fonts 桩（既有 jsdom 教训先例）。
