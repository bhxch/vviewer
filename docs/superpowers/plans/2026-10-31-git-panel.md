# git 信息面板（纯前端 isomorphic-git）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 右面板第三段 `[目录 | 属性 | Git]`：分支/末次提交/状态信息卡、行级 blame hover、diff 视图（工作区 vs HEAD / clean 时 HEAD vs HEAD^）、文件历史 log（≤50 条点击展开详情）——纯前端 isomorphic-git，服务端零改动。

**Architecture:** git worker（独立 Worker，isogit 全部计算 worker 内）+ GitFsAdapter（isogit fs 接口 → tab.source.store 的 read/listChildren 适配，只读承诺）+ gitClient（消息协议/取消/缓存，仿 outline 通道骨架）；能力探测 = 文件目录向上 ≤5 级读 `.git/HEAD`（目录级缓存+负缓存，打开文件后台触发）；右面板切换器扩三元（探测可用才显示 Git 段）。

**Tech Stack:** isomorphic-git（新增依赖，动态 chunk 排除 precache 四件套）、Svelte 5 runes、playwright（真实 git 仓库夹具：execSync git init/commit）。

**Spec:** `docs/superpowers/specs/2026-10-31-git-panel-design.md`

## Global Constraints

- 只读承诺：GitFsAdapter 写方法（writeFile/mkdir/rmdir/unlink/symlink/lstat 写面）一律 throw；无启动期/后台自动网络请求（isogit 零 remote 操作）。
- 探测：从文件所在目录向上逐级读 `.git/HEAD`（≤5 级），**缓存键 = 目录路径**，失败记负缓存（同会话不重试）；`.git` 为文件（worktree 形态）读 `gitdir:` 指向，store 内可达才可用（v1）；url/zip/single 来源天然不可用。
- 状态比对用**原始字节**（store read 原始通道，绕开渲染归一文本——CRLF 免误报）；blame/diff 渲染用渲染归一行号口径。
- blame 历史上限 200 截断 + UI 标注；log depth 50；diff 输出 >2000 行或 >200KB 截断 + 尾注（常量实现内）。
- isomorphic-git chunk **不进 precache 四件套**：vite diagramEngineChunk groups 增 `[\\/]node_modules[\\/]isomorphic-git[\\/]`（+其独占传递依赖正则，实测定）+ chunkFileNames 特判名 `git-engine-[hash].js` + workbox globIgnores 追加 `**/git-engine-*.js` + tools/diagram-budget.mjs 扫描面追加该前缀（预算内计账）。惰性加载时机 = 首次激活 Git 段。
- 浮层 blame hover：**事件委托**在 pre 容器（行 DOM 每次滚动 replaceChildren 整批重建，行级监听必死）；fixed 定位浮层（TabContextMenu 模式）+ scrollHost scroll 捕获即收。
- abort 语义：git worker 请求层可取消（仿 pendingOutline/cancelOutline 骨架）；TreeStore.listChildren 无 signal——列举不可中断为知情降级（spec §2.1 注记）。
- 大仓边界记档：packfile 整读（isogit fs 无 range）、>50MB pack 慢源首拉慢；会话级 worker 内存缓存（无 LRU，worker 生命周期即会话）。
- 工作树 server/core/build.rs 属并行会话——scoped add；门禁 HEAD 口径。

## Review Focus

- GitFsAdapter 路径映射：isogit 的 `dir`/`gitdir` 语义与适配层前缀拼接（repoDir 相对前缀 + '/' + 路径）——`../` 逃逸面（isogit 内部路径拼接是否会产生 `..`——适配层 normalize 后断言仍在 repoDir 前缀内，越界 throw）。
- probe 的负缓存失效：HEAD 变化（切分支）不影响可用性判定（负缓存只存「无仓库」），可用缓存键须含 HEAD 内容吗？——裁决：可用性只随目录定（.git 在不在），HEAD 内容在信息卡读取时现取， probe 缓存不掺 HEAD。
- blame 行号映射：worktree 归一文本（CRLF→LF/BOM 剥）与 git blob 字节的行对应——blame 以 **blob 归一后行号**对齐渲染行（渲染器与 blob 同走归一通道时行号一致；HEAD blob 与工作区 blob 归一规则一致化处理），夹具含 CRLF 文件验证。
- 切换器三元与 spec ④ 的 rightViewTouched 语义组合：Git 段激活是否置 touched（裁决：置——用户显式选择）；默认落位永不选 git（有大纲默认目录，无大纲默认属性）。
- isogit 在 worker 内的浏览器兼容（`fs` 接口注入 vs 内置 lightning-fs——必须显式传 fs，禁用其 IndexedDB 内置 fs）。
