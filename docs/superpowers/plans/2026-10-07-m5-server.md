# M5 后端档 1：axum 文件服务 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rust + axum 单二进制后端（档 1 文件服务）：health 能力发现、目录树、Range 文件流 + 服务端检测、SSE 变更推送、token/ticket 鉴权、路径安全；前端 RemoteStore 与服务器连接 UI 接入 TreeStore。

**Architecture:** `server/` 独立 Cargo workspace（bin `vviewer`）：axum 0.8 + tokio + notify + tower-http；静态资产 RustEmbed 内嵌 `apps/web/build`（构建脚本驱动 pnpm build 或运行时 `--web-dist` 指定目录双模式，M5 先 `--web-dist`+可选 embed）。前端 `RemoteStore` 实现 TreeStore（packages/core），连接 UI 在 TopBar。

**Tech Stack:** axum 0.8、tokio（fs//process）、notify 7（watch）、tower-http（cors/trace）、serde/serde_json、tokio-test；前端无新依赖（fetch/EventSource——SSE 经 ticket query）。

**Spec:** `docs/superpowers/specs/2026-10-06-vviewer-design.md`（5.9 变更监听 / 5.10 后端 API 与安全 / M5 里程碑行 / 决策 Q4 token）

## Global Constraints

- 沿用全局约束；Rust 侧 edition 2021、`#![deny(warnings)]` 不强求但 CI 级别 `cargo clippy` 无 error。
- **环境事实**：cargo 1.98 可用；crates.io sparse index + static 下载 GET 200（web API 403 不影响 cargo）。
- 全部接口只读；`/api/health` 免认证；其余需 `Authorization: Bearer <token>`；SSE 用 `POST /api/ticket` 换 30s 一次性 ticket 后 `?ticket=`。
- bind 默认 127.0.0.1；`--allow-lan` 且未配 token 时拒绝启动（exit 非 0 + 明确错误信息）。
- 路径安全：请求 path 相对 root，canonicalize 后必须仍在 root 内；symlink resolve 后越界一律 403。
- M5 验收：cargo test 全绿（路径穿越/Range/token/ticket/SSE debounce）；E2E server 模式（起 server → 前端连接 → 目录树 → 打开文件 → 修改文件自动刷新）连续 2 次全绿。

### Task 1: Cargo workspace 骨架 + health + 静态资产

**Files:** Create `server/{Cargo.toml,src/main.rs,src/state.rs,src/error.rs}`、`server/tests/health.rs`；Modify 根 `package.json`（script `server:dev`）
**Interfaces:** `GET /api/health` → `{"name":"vviewer","version":"0.1.0","capabilities":["file-server"]}`（`--compute` 时附加 "compute"，M6 前恒 file-server）；`GET /` 与非 /api 路径 → 静态 dist（`--web-dist DIR` 指定，ServeDir fallback index.html）；CLI：`vviewer serve --root DIR [--web-dist DIR] [--port 8321] [--token T|--token-gen] [--allow-lan] [--hidden] [--cors-origin URL]`（clap）。`--allow-lan` 无 token 拒启。
**Steps:** cargo new + 依赖（axum/tokio/clap/serde/tower-http/notify/tracing）→ health 测试（tower::ServiceExt oneshot）→ 绿 → Commit `feat(server): axum 骨架与 health 能力发现`

### Task 2: /api/tree 与 /api/file（Range + 检测）

**Files:** Create `server/src/{routes/tree.rs,routes/file.rs,detect.rs}`；Test `server/tests/tree_file.rs`
**Interfaces:**
- `GET /api/tree?path=` → `{entries: [{name, kind, size?, mtime?}]}`（单层；目录优先+名称自然排序——Rust 侧实现自然排序 compare；`--hidden` 反向开关：默认显示全部，`--hidden` 时过滤 dot 开头）。
- `GET /api/file?path=` → 流式 body（tokio::fs::File → ReaderStream）；Range 头解析（单区间 bytes=a-b/a-/suffix，多区间取第一个，416 语义正确）；响应头 `Content-Length/Accept-Ranges/Content-Type`（Rust 侧扩展名→MIME 小表 + 二进制兜底 `application/octet-stream`）+ `X-VV-Lang`（扩展名映射表，从构建期 languages.json 生成 Rust 静态表——include_str! packages/highlight/assets/languages.json + serde 反序列化构建 HashMap）+ `X-VV-Encoding`（BOM/UTF-8 校验逻辑 Rust 版，读前 8KB）。
**Steps:** 集成测试（临时目录树：嵌套/中文名/空文件/大文件 Range 3 种形态/416/隐藏过滤/中文排序）→ 实现 → 绿 → Commit `feat(server): 目录树与 Range 文件流（服务端检测头）`

### Task 3: 安全——canonicalize/token/ticket/CORS

**Files:** Create `server/src/{auth.rs,guard.rs}`、`routes/ticket.rs`；Modify `main.rs/state.rs`；Test `server/tests/security.rs`
**Interfaces:**
- 中间件：`Authorization: Bearer <t>` 校验（constant-time 比较）；`/api/health` 豁免；无 token 配置（127.0.0.1 默认）时全部放行。
- `POST /api/ticket`（Bearer 有效）→ `{ticket}`（随机 32B hex，一次有效，30s 过期，内存 MFT）；`GET /api/events?ticket=` 校验后升级 SSE。
- guard：每请求 resolve（`pathclean + tokio::fs::canonicalize`）→ `starts_with(root_canonical)` 否则 403；`..` 段直接 400；URL decode 后再校验。
- CORS：`--cors-origin` 时 CorsLayer 精确 origin，否则无 CORS 头。
**Steps:** 测试（穿越 `../`/编码 `%2e%2e`/symlink 出 root 403/越界内 symlink 放行；token 缺失 401/ticket 流程/SSE 无 ticket 401）→ 实现 → 绿 → Commit `feat(server): 鉴权与路径安全（canonicalize/ticket/CORS）`

### Task 4: SSE 变更推送（notify + debounce）

**Files:** Create `server/src/routes/events.rs`、`src/watch.rs`；Test `server/tests/events.rs`
**Interfaces:** `GET /api/events?ticket=` → `text/event-stream`；事件：`data: {"type":"changed","paths":[...]}`（notify RecommendedWatcher 递归 watch root → mpsc → 500ms debounce 聚合 → broadcast 到所有 SSE 连接）；watcher 建立失败的降级：SSE 连接保持但发一条 `{"type":"watch-error"}` 后静默。心跳：15s `: ping` 注释行。
**Steps:** 测试（tokio::time 假时钟或 1s 真延时：写文件 → 500ms 内聚合一条 changed 含该 path；多写聚合计数=1）→ 实现 → 绿 → Commit `feat(server): SSE 变更推送（notify + 500ms debounce）`

### Task 5: 前端 RemoteStore 与服务器连接 UI

**Files:** Create `packages/core/src/tree/remote.ts`；Modify `apps/web/src/lib/openFlow.svelte.ts`（connectServer）、TopBar（连接服务器按钮 + 地址/token 输入对话框）、`viewer.ts`（X-VV-* 头消费：fetch /api/file 后读响应头喂 Detection）；Test `packages/core/test/treeRemote.test.ts`
**Interfaces:** `createRemoteStore(baseUrl, token, dirLabel): TreeStore`——listChildren→`GET /api/tree?path=`（fetch + Bearer）；read→`GET /api/file?path=`（X-VV-Lang/X-VV-Encoding 读出后存 store 级 meta 表供 code renderer 使用——裁决：RemoteStore.read 返回 Uint8Array 时把头信息写进 module 级 `remoteMeta: Map<storeKey+path, {lang, encoding}>`，codeRenderer langdetect 前 check 该表）；Range 不用（renderer 全量 read；hex 1MB 场景 read 全量可接受，M6 优化）；displayName=dirLabel。会话：RemoteStore 不可持久句柄——TabSnapshot kind 'rename-only' + storeLabel 记 base+dir（M7 做重连恢复，本期手动重连）。连接对话框：地址（http://127.0.0.1:8321）、token（可空）、连接 → health 校验 → addDirStoreTab(remoteStore)（目录 tab 替换语义复用）。
**Steps:** 失败测试（fetch stub：listChildren/read/401 抛错/X-VV meta 写入）→ 实现 → 绿 → Commit `feat(core/web): RemoteStore 与服务器连接 UI`
