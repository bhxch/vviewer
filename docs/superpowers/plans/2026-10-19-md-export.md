# Markdown 导出 HTML/PDF Implementation Plan（spec 阶段五+六）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** markdown tab 新增「导出 HTML」（自包含单文件：内联主题样式+图片 data URI+KaTeX 字体裁剪+静态 TOC）与「导出 PDF」（隐藏 iframe 打印模板：@page 分页保护+大图缩放+mermaid 浅色重画，浏览器原生出 PDF）。

**Architecture:** 导出装配纯函数集 `packages/render-text/src/markdown/export.ts`（collectExportHtml(doc, assets)/buildPrintDocument(html, opts)——输入为管线后的 Document 与资产清单，可单测）；触发壳在 apps/web（MetaPanel 动作区 + markdownRenderer 实例句柄 getExportDocument()）；PDF=隐藏 iframe + `contentWindow.print()`（Chromium 手势链路内），如 iframe print 被策略拦降级 window.print 作用域方案（spec §7 既定，二选一实施时验证）。

**Tech Stack:** DOMPurify 既有管线、Blob+URL 下载、iframe print、vitest/jsdom、playwright（下载事件断言）。

**Spec:** `docs/superpowers/specs/2026-10-19-markdown-markpad-alignment-design.md` §6、§7

## Global Constraints

- 入口：MetaPanel「导出」区仅 markdown 渲染 tab 显示（Tab.overrideRenderer 指向 markdown 时也显示——以实例句柄可得性为准）；导出走浏览器下载（Blob+a[download]），文件名 `<原名>.html`/`<原名>.pdf 触发打印`。
- HTML 导出内容基线：克隆**管线完成后**的 DOM（代码高亮/katex/图表 SVG 已成品）；lightbox/复制钮/图表切换钮等交互壳剥离（rg 'data-md-copy|md-lightbox|md-diagram-toggle' 剥离清单）；音视频占位降级为源地址超链接（防 data URI 爆炸）。
- 图片 data URI：`blob:`/同源相对图（已解析 blob）fetch→base64；**外域 http(s) 图保留原 URL 不强拉**（CORS 不可控）；fetch 失败保留原 URL 降级。
- KaTeX 字体裁剪：按文档实际用到的字体族嵌 @font-face（markpad exportFonts 思路）；实现取「扫 .katex 产物 class→字体族集合→从 katex fonts 目录取 woff2 转 data URI」。
- mermaid/图表 WYSIWYG（HTML 导出保持当前主题）；PDF 路径 mermaid 强制浅色重画（复用 Plan 1 的 renderMermaidInto+theme='default'，仅对 data-mermaid 容器）。
- TOC：静态锚列表（h1-h4 + href=#user-content-最终 id），无滚动跟踪脚本。
- 不引入任何 npm 依赖（puppeteer/paged.js 均不用）。

### 实施风险与裁决预留

- mermaid 浅色重画在 detached 克隆上的可行性未知（Task 2 内实测校准）；不可行时降级「PDF 保持当前主题」并在 spec §7 注记偏差（知情接受，不再阻塞）。
- KaTeX 字体裁剪的字体族→woff2 映射需实读 node_modules/katex/dist/fonts 清单；裁剪实现复杂度超预期时降级「全量嵌入 katex.css+字体（约 395KB+）」并在报告注记（spec 允许全嵌为上限形态）。
- iframe print 的 sandbox/权限问题（Chromium 需用户手势——按钮点击链路天然满足；若 srcdoc iframe print 被拦截，降级方案=主文档 window.print + @media print 隐藏其余元素 + 打印样式表注入，二选一不并存）。
